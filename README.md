# SMK Fashion Hub — Mobile First

A mobile-first Chudidhar / Ladies Wear boutique website inspired by the supplied peaceful luxury mockup.

## Included
- Mobile-first responsive layout
- Peaceful cream / rose boutique palette
- Hero, collections, new arrivals, offer banner, service strip, about and footer
- Product filtering
- Shopping bag with localStorage
- WhatsApp ordering
- Vercel-ready static deployment

## Update later
Edit the `products` array in `script.js` for product names, categories and prices.
Replace the WhatsApp number in `script.js`.
Replace the placeholder model/product blocks with your own images whenever ready.

## Deploy
Import this folder/repository into Vercel. No build command is required.
